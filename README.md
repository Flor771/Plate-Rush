# PLATE RUSH 🇩🇴

**The Dominican Street Game**

Juego móvil arcade inspirado en el tradicional juego dominicano **La Placa**.

## Primera versión
- Controles táctiles.
- Batear, correr y regresar.
- Marcador.
- Funciona directamente en el navegador del teléfono.
- Base preparada para convertirlo posteriormente en una aplicación Android.

## Probar
Abre `index.html` mediante GitHub Pages o un servidor web.

> Proyecto independiente. No modifica ni depende de los proyectos SERVIYA.
